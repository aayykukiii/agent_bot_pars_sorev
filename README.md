# Agent Bot Pars Sorev

**Описание проекта**

- **Назначение:** Парсить вакансии с сайтов (Habr Career, SuperJob), сохранять в SQLite и предоставлять интерфейс для администратора в Telegram для просмотра, листания и удаления вакансий.

**Структура репозитория**

- `main.py`: точка входа — инициализация бота и роутеров.
- `config.py`: конфигурация (TOKEN телеграм-бота и `ID_ADMIN`).
- `parsing_vakanc/pars.py`: парсеры сайтов — возвращают список вакансий (словарей).
- `database/`:
	- `db.py`: SQLAlchemy engine, `SessionLocal`, `Base`, helper `create_tables()`.
	- `models.py`: ORM-модели (`Vacancy`, `Skill`, `User`, `Favorite` и связующая таблица `vacancy_skill`).
	- `crud.py`: функции создания/чтения/удаления записей.
- `handlers/`: aiogram-роутеры и обработчики
	- `admin_commands.py`: команда `/admin` и кнопки администратора.
	- `admin_obrabotka.py`: обработка кнопки "просмотр вакансий", листание и удаление.
	- `user_panel.py`, `user_obrabotka.py`: пользовательские обработчики.
- `alembic/` + `alembic.ini`: миграции базы данных.

**Установка и запуск (локально)**

1. Клонировать репозиторий и перейти в папку проекта.
2. Создать виртуальное окружение и установить зависимости (пример):

```powershell
python -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Если `requirements.txt` нет — установите минимум:

```powershell
pip install aiogram aiohttp beautifulsoup4 sqlalchemy alembic
```

3. Настроить `config.py` — указать `TOKEN` и `ID_ADMIN`.

4. Применить миграции Alembic (рекомендуется):

```powershell
alembic upgrade head
```

5. Запустить бота:

```powershell
venv\Scripts\python.exe main.py
```

Опционально: создать таблицы напрямую (только в dev):

```powershell
venv\Scripts\python.exe -c "from database.db import create_tables; create_tables()"
```

**Как пользоваться (админ)**

- В Telegram отправьте команду `/admin` (только для `ID_ADMIN`).
- Нажмите кнопку `просмотр вакансий` — бот запустит парсеры, сохранит новые вакансии в БД и пришлёт отчёт:
	- `Парсер Habr: найдено N`
	- `Парсер SuperJob: найдено M`
	- `🔔 Обновление завершено. Найдено: X. Добавлено новых: Y.`
- После этого бот отправит первое сообщение с вакансией и кнопками:
	- `⬅️ Назад`, `▶️ Следующая` — листание по сохранённым вакансиям;
	- `🗑 Удалить` — удалить текущую вакансию из БД.

**База данных и миграции**

- Проект использует SQLite `bron.db` в корне проекта. Alembic настроен в `alembic.ini` и каталоге `alembic/`.
- В продакшне используйте Alembic для миграций; прямой вызов `Base.metadata.create_all()` в коде не рекомендуется.

**Отладка и частые проблемы**

- Если бот пишет `no such table: vacancies` — проверьте, что миграции применены (`alembic upgrade head`) или создайте таблицы через `create_tables()`.
- Если парсеры падают на Windows из‑за эмодзи в консоли — парсеры обновлены, они возвращают списки и не печатают эмодзи.
- Проверьте рабочую директорию при запуске — `bron.db` расположен в корне проекта.
